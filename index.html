spot

Your always-on agent

A spot watches your infrastructure through Triage and keeps working when you are away. It holds its tasks, scope and conversation between visits, so it picks up where it left off.

Harness · connectors

A spot is a harness around the model: memory, tools, skills and a sandbox that run it, and connectors to Kubernetes, monitoring, cloud, messengers and MCP. The model can change; the harness is what keeps the spot the same agent.

Chat · voice · background

Ask it in chat, talk to it by voice, or hand it a task and hang up: “prepare an RCA for each issue from last week” runs in the background. It will chat with you as a teammate.

Substrate · sandboxes

Each spot runs in its own sandbox on Agent Substrate: an actor that suspends when idle, snapshots, and resumes with its tasks and conversation intact.

ego

Reality testing for AI agents

Continuous evaluation

ego samples live sessions from the OpenTelemetry traces your agents already emit, scores them, and alerts when quality drops. There is no SDK to add, and it never re-runs the agent.

Recursive self-improvement

A loop of sample, score, detect, diagnose, correct and verify. When scores drop, ego explains why, hands the diagnosis to the agent over MCP, records what the agent changed and checks that the scores recovered.

Self-improving always-on agents

For an always-on agent like a spot, ego follows its work as one continuous thread. The spot reads its findings over MCP, makes one change per finding and learns from the verdict.

tria

Your triage teammate

Tria knows your workspace: its services and how they call each other, its past issues, and what the team learned from them. Tria speaks first, when something matters, with what it knows.

Speaks first

When an issue opens or resolves, Tria says so in the workspace chat, with the likely cause from what the workspace has seen before, so the team sees it where it already talks.

Knowledge that grows

Every issue adds to what Tria knows: patterns, facts and a map of how services connect. The next time something similar happens, the context is already there.

Ask · speak

Talk to Tria in chat or by voice when you want more. Mention @tria in a workspace chat and the whole room sees the answer. Tria asks before any change.

xray

Agentic memory substrate

xray is the memory under Triage and a research project in its own right. Everything an agent observes or concludes is a memory cell: searchable by meaning, linked into a living graph, consolidated by reflection and knowledge loops, and let go when it stops mattering.

Memory for any agent

The agent’s own prompts and mental maps live in the same memory, which is what makes self-improvement possible. Over MCP, xray is recall, remember and forget for any agent, not only Triage.

White paper, section 7: Cognition

Foundations

What Triage is built on, and who to thank for it.

CoALA memory

Working, episodic, semantic and procedural memory as separate modules, with one decision loop over them. Triage lays its memory out the same way: issues and events as episodes, facts and patterns as knowledge, compiled rules as procedure.

Sumers, Yao, Narasimhan & Griffiths, Cognitive Architectures for Language Agents, 2023 · white paper, section 2

Dual-system thinking

A fast, cheap System 1 for the routine and a slow, deliberate System 2 for what deserves it. Triage answers with reflex rules and small models first and reasons only when the cheap answer is not enough.

Daniel Kahneman, Thinking, Fast and Slow, 2011 · white paper, section 2

USE RED SIGNALS

Utilisation, saturation and errors for resources. Rate, errors and duration for services. Latency, traffic, errors and saturation as the four golden signals. Triage measures every service with these three families, so a reading means what an SRE expects it to mean.

Brendan Gregg, The USE Method, 2012 · Tom Wilkie, The RED Method, 2015 · Google, Site Reliability Engineering, 2016 · white paper, section 5

Jev, the decision model

The System 1 judge. Every event passes Jev for guardrail, routing, severity and prognosis: fast, cheap and bounded, the only model in the event path. Reasoning happens elsewhere, and only when Jev says it is worth it.

white paper, section 2

Claude Code

Spots run on Claude Code, Anthropic’s agent runtime: a persistent session in a sandbox with Triage’s tools over MCP, so a spot plans, reads and acts with the discipline of an engineer at a terminal.
